# Site Oral Centter · Teixeira de Freitas (BA)

Proposta de site para a clínica odontológica Oral Centter, criada pela Verus Soluções inteligentes.

- Página única (`index.html`), sem dependências: abra no navegador ou publique com GitHub Pages.
- Conceito: a abertura forma o logo da clínica conforme a rolagem (linha → sorriso → anel → logo).
- Dados de contato, nota e avaliações tirados do perfil público da clínica no Google.
