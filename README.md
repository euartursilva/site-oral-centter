# Site demonstração · Oral Centter

Proposta de site criada pela **Verus Soluções Inteligentes** (@verus.solutions) para a Oral Centter, clínica odontológica em Teixeira de Freitas (BA).

Site (demonstração): https://euartursilva.github.io/site-oral-centter/

Esta é uma demonstração para apresentação ao cliente, não o site oficial da clínica. A página está marcada como `noindex` para não aparecer no Google.

- `index.html`: página única, sem dependências (logo embutido)
- Abertura: a linha vira sorriso e forma o logo da clínica conforme a rolagem
- Botões de WhatsApp e Instagram, depoimentos com "digitando…" e animações ao rolar; quem usa "reduzir movimento" vê o site parado

Para rodar localmente: `py -m http.server 8092` e abra http://localhost:8092
